Integração de Formulário Web com Google Sheets

Projeto desenvolvido com HTML, CSS e JavaScript para capturar dados enviados por requisições no front-end e armazená-los automaticamente em uma planilha do Google Sheets utilizando a API do Google para autenticação e credenciamento das informações.

Funcionalidades: 
Captura de dados via formulário/requisições,
Envio automático para uma planilha Google Sheets,
Integração com API do Google,
Interface simples e responsiva,
Organização automática das informações recebidas.

Tecnologias Utilizadas: 
HTML5,
CSS3,
JavaScript,
Google Sheets API,
Google Cloud API Credentials.

Objetivo: 
Automatizar o armazenamento de dados recebidos pelo sistema, facilitando o gerenciamento e a visualização das informações diretamente em planilhas online.

Como funciona: 
O usuário envia as informações pelo formulário.
O JavaScript processa os dados.
A API do Google autentica a requisição.
Os dados são enviados automaticamente para a planilha configurada.
